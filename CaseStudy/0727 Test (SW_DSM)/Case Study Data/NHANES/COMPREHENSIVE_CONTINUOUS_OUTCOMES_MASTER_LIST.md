## 🎯 SELECTION CRITERIA FOR NEXT 5 ANALYSES

**Priority factors:**
1. ✅ **Clinical impact:** Well-known associations (e.g., smoking→lipids, PA→BP)
2. ✅ **Sample size:** >15,000 for adequate power
3. ✅ **Data quality:** Low missingness (<20%)
4. ✅ **Publication support:** Existing papers for context
5. ✅ **Scientific novelty:** Sample-population bias likely large
6. ✅ **Policy relevance:** Modifiable risk factors

## 📋 IMPLEMENTATION STRATEGY

### **For Each Analysis:**

**Step 1: Data Preparation**
- Load NHANES 2007-2018
- Define binary treatment (median split or clinical cutoff)
- Extract continuous outcome
- Identify covariates
- Create complete case dataset

**Step 2: All 5 Methods**
- Unweighted DSM (Sample ATE)
- Unweighted PGM (Sample ATE)
- Unweighted PSM (Sample ATE)
- Survey-Weighted PS Full (Population ATE)
- WDSM (Population ATE)

**Step 3: Results Table**
- Point estimates
- Bootstrap 95% CIs
- Sample vs Population comparison
- Bias calculation
- Clinical interpretation

**Step 4: Documentation**
- Research question
- Motivating publications
- Sample characteristics
- Covariate balance
- Publication-ready table
