\textbf{Note:} PS = propensity score model, PGS = prognostic score model. Under each score model column, $\checkmark$ = survey-weighted estimation, $\times$ = unweighted estimation, \textendash\, = score not used by the method. Prognostic scores are estimated without survey weights for all methods, as established in Section \ref{subsec:score_models}. WDSM additionally incorporates survey weights in within-match imputation and Hájek normalization (Table \ref{tab:weight_requirements}). Model specifications: Cor|Cor = both PS and PGS correctly specified, Mis|Cor = PS misspecified with PGS correct, Cor|Mis = PS correct with PGS misspecified, Mis|Mis = both misspecified. Correctly specified models include all six main effects plus the $X_{1i}X_{2i}$ interaction, while misspecified models omit this interaction. Relative efficiency is the ratio of the Monte Carlo variance of PSM under Cor|Cor to that of each method. PSM = propensity score matching, PGM = prognostic score matching, DSM = double score matching, SW-PSM = survey-weighted propensity score matching, WDSM = weighted double score matching. All methods use $M = 5$ nearest neighbors with replacement. WDSM uses polynomial sieve bias correction and linearization-based bootstrap variance estimation with $B = 200$.
