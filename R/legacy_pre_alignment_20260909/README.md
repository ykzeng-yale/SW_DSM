# Superseded diagnostic implementation

These exact files preserve the code at commit `1bc5fff` before the full PATE/PATT alignment. They are historical evidence, not the final rerun API. The original paper version remains in Git commit `3356769` and the immutable 0727 release. The initial diagnostic PATE run used stable PS fitting and corrected fixed reuse/Wald intervals but retained the historical logit/joint-sieve point estimator. It was canceled when the full alignment was authorized. Use `R/wdsm_core_final.R` and `Simulations/rerun_wdsm_final.R` for current work.
