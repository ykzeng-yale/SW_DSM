PSM, PGM, and DSM use $M=1$ matching with replacement; SW-PSM uses optimal full matching; WDSM uses $M\in\{1,3,5\}$. All intervals are centered normal Wald intervals. WDSM uses fixed-original-reuse replication variance with divisor $B$; PSM, PGM, and DSM retain the author's bootstrap sample variance with divisor $B-1$; SW-PSM uses subclass-cluster sandwich/delta-method variance.
