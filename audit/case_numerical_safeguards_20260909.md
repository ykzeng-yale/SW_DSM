# Case-study numerical safeguards and rerun protocol

The September 7 case-study corrections already use the manuscript's probability-scale, own-arm double scores; pooled unweighted component moments; count-only prognostic refits; survey-weighted own-arm quadratic bias correction; fixed original weighted reuse; B-divisor replication variance; and Wald intervals. Those estimator and inference formulas did not require another change.

This update adds the same numerical propensity checks used by the final simulation core to the two standalone case-study functions: zero-coefficient initialization, up to 100 iterations, finite full-rank coefficients, nonsaturated finite probabilities, and a dimensionless logistic score residual at most 1e-7. NHANES retains its common survey-weight normalization; NSDUH retains unweighted/count-only propensity fitting. Common normalization and zero initialization solve the same estimating equations. Per-fit diagnostics are retained. A nonfinite NSDUH reuse coefficient now stops instead of being replaced by zero. This branch has not demonstrated that this fallback occurred in the previously published fits.

The original case-study scripts already checked convergence, and the common NHANES normalization had already addressed the default raw-weight initialization failure observed in simulations. This is additional numerical verification, not evidence that the September 7 case-study numbers were wrong. Existing sample selection, covariate coding, model formulas, matching, M, B=200, fixed-reuse replication, and Wald construction are preserved.

The independent final-core suite passed 318 checks after these case-source edits, including same-count synthetic parity with the standalone NHANES and NSDUH implementations. No shared-core changes were needed. The two original inputs were checksum verified; preparing them gives NHANES n=3,793 (1,002 treated) and NSDUH n=17,471 (1,877 treated). No participant data or fitted model objects are added to GitHub.

`CaseStudy/case_rerun_config.R` freezes both input identities and the exact prior RNG protocol. `CaseStudy/rerun_wdsm_final.R` runs five separate fits: NHANES M=1/3/5 and NSDUH AMIPY/SMIPY at M=5. NHANES seeds once at 2024, advances the five earlier samples by 150 multinomial draws each, then restores each original M-specific start separated by 50 draws. NSDUH resets 2024 per outcome. Each fit requires all 200 replications and writes a new isolated result, including all replication estimates and numerical diagnostics, without participant records or fitted models. It records differences from the previous published CSV rather than assuming equality.

`CaseStudy/submit_wdsm_final.sbatch` requests one CPU and 8 GiB per fit, caps numerical-library threads at one, and requires a frozen code commit plus externally supplied data and output paths. Source must be committed and transferred before submission. Execution status and numerical comparison will be added after the five Slurm jobs finish.

These checks do not establish the nonparametric sieve remainder rates, estimated-score/bootstrap asymptotics, or design validity for arbitrary multistage survey samples. Pooled unweighted moments and a fixed complete quadratic remain concrete implementation choices consistent with the previously corrected cases; the manuscript explicitly specifies probability-scale own-arm scores but does not uniquely prescribe those finite-sample choices.
